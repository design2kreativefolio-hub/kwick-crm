Employee User Guide

Kreativefolio — Internal CRM

Live site: https://kwick.kreativefolio.com

This guide is for employees. It covers how to get access, sign in, and use the tools you’ll need day to day.

1. Getting access (first time)

Option A — Register yourself

  1. Open https://kwick.kreativefolio.com/register
  2. Enter your full name, work email, and a strong password (then confirm it)
  3. Submit the form
  4. Your account stays pending until a company admin (superadmin) approves you
  5. After approval you usually get an email with a Set password link — open it, choose your password, then go to Login
  6. Sign in with your email and password
Tip: If login says you’re not approved yet, wait for your manager/admin to approve you on the Dashboard.

Option B — You already have an account

  1. Open https://kwick.kreativefolio.com/login
  2. Enter email and password
  3. Click Sign in

Forgot password?

  1. On the login page, click Forgot password?
  2. Enter your email and follow the reset link sent to you
  3. Set a new password, then sign in again

3. What to do every day (recommended routine)

Morning (or whenever you start)

  1. Open Dashboard
  2. Check the Reminders card on the right
    • Open calendar reminders assigned to you
    • Your open to-dos
    • Unread notifications
  3. Open Tasks — work through items assigned to you
  4. Open Calendar — see today’s reminders, to-dos, and deadlines
  5. Skim Chat for teammate messages
  6. Check Reminders (notification inbox) if anything important arrived overnight

During the day

  • Update task status as you work (todo → in progress → completed)
  • Add personal notes to To-Do (your private checklist)
  • Add timed Calendar reminders for meetings or follow-ups
  • Reply in Chat when teammates ping you
  • Use EDITH if you need a quick briefing, how-to, or help drafting text

End of day

  • Mark finished tasks / to-dos / reminders as done
  • Leave unfinished items clear so tomorrow’s Dashboard card stays accurate

4. Core tools (every employee)

Dashboard

  • See a snapshot of work and the Reminders card
  • Tick on a card item = hide it from the card only (does not mark it done)
  • Refresh (circular arrow) = bring dismissed pending items back
  • To clear something for real: mark it done on Calendar / To-Do, or mark the notification read on Reminders

You’ll also get gentle nudges Mon–Sat around 9:15 AM, 2:30 PM, and 5:00 PM (Dubai time) if you still have open reminders or to-dos. If you were offline, you’ll see them when you next log in. No nudges on Sundays.

Tasks

  • Shared work items assigned to people
  • Open Tasks, find your items, update status and finish them when complete
  • This is not the same as To-Do or Calendar Reminders

To-Do

  • Your personal checklist
  • Add items (optional due date), tick when finished
  • To-dos can also show on your Calendar and Dashboard card
  • Creating a to-do does not create a Calendar reminder

Calendar

  • Your agenda: tasks, to-dos, reminders, and other dated items
  • Add Reminder = timed reminder (you can assign teammates, add a meeting link, set recurrence)
  • Creating a reminder does not create a to-do
  • Mark reminders done when finished so they leave the Dashboard card

Reminders (notification page)

  • Inbox of in-app notifications
  • Separate from Calendar reminders
  • Mark as read when you’ve seen them

Chat

  • Message colleagues inside Kwick
  • This is team chat — not EDITH

EDITH (AI assistant)

  • Ask things like “What needs attention?”, “How do I request leave?”, or “Draft a short client follow-up”
  • EDITH can look up info (read-only) and help with writing/ideas
  • She cannot click buttons or change records for you — she tells you which screen to use

Projects

  • Mini-Projects — jobs you’re on; update progress when asked
  • Clients (under Projects) — delivery / content calendar for clients
  • Artwork Generator — create artwork IDs when your workflow needs them

Profile (do this once, then as needed)

  1. Open Profile
  2. Upload / crop your photo so teammates recognize you
  3. Confirm your name and details
  4. Use Leave Requests to apply for leave
  5. Use Raise Ticket if something is broken or you need internal help

Support

  • External help: email design@kreativefolio.com or WhatsApp +971 50 521 1969
  • Day-to-day internal issues → Profile → Raise Ticket or ask in Chat

5. Common how-tos

Request leave

  1. Profile → Leave Requests
  2. Choose type (annual, sick, unpaid, other), dates, submit
  3. Wait for HR/admin approval

Raise an internal ticket

  1. Profile → Raise Ticket
  2. Set urgency and describe the issue
  3. Track replies / status as needed

Create a meeting reminder

  1. Calendar → Add Reminder
  2. Title, date/time, optional assignees and meeting link
  3. Save — it appears on Calendar and the Dashboard card for you (and assignees)

Add a personal checklist item

  1. Open To-Do
  2. Add text (and due date if useful)
  3. Mark done when finished

Catch up on what’s pending

  1. Open Dashboard → Reminders card
  2. Or ask EDITH: “What needs attention?”

7. Good habits

  • Keep task status up to date so managers see real progress
  • Don’t confuse Tasks / To-Do / Calendar Reminder / Notifications — they are four different things
  • Prefer Chat for quick teammate questions; Ticket for formal issues; Support for external Kreativefolio contact
  • Use a strong unique password; use Forgot password if locked out
  • Sign out on shared computers
